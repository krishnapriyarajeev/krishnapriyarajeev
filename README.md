## 👋 Hi, I'm Krishnapriya

I'm an AI engineer in Kochi. For about two years I've been shipping LLM agents and the backend and data systems under them, and before that I built computer vision systems that run on the edge.

- 🧠 **Now:** a conversational analytics agent that turns plain-English questions into guarded SQL, charts and dashboards
- 🛒 **Before that:** a LangGraph shopping assistant for a large US retail-health company, plus its Dataflow and BigQuery pipelines
- 👁️ **Where I started:** YOLO11, RF-DETR and TensorRT on NVIDIA Jetson, trained through SageMaker pipelines
- 🎙️ **On the side:** [PitchMe](https://github.com/krishnapriyarajeev/pitchme), a rehearsal room that talks back
